# Handoff для Mac

Установщики Handoff — программы, которая находит клиентов, уже ищущих исполнителя.

Сайт: https://handoff.vizi.club/desk/

Скачать последнюю версию: [Handoff.dmg](https://github.com/arablex/handoff-releases/releases/latest/download/Handoff.dmg)

Первый запуск: macOS может предупредить о неизвестном разработчике — откройте Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
